# 1. Pre-anesthetic Examination

#### Pre-anesthetic Examination in Veterinary

수의학에서 마취전 평가가 중요한 이유?
- 수의학에서는 환자의 정보가 간접적으로 전달되기 때문에 마취전평가가 훨씬 중요하다.
- 환자가 병원에 와서 흥분하면 증상이 가려질 수 있다.
- 종에 따라 정상 범위나 요인도 크게 달라지기 때문에 더욱 중요.

마취전 검사를 어디까지 해야 하느냐? 답이 정해져 있진 않다. 주치의나 마취과 의사의 결정.

그럼에도 '이 정도는 검사해라' 하는 것 중 하나가

#### PCV (Packed Cell Volume)

→ 대부분의 산소는 적혈구와 결합하고, 일부가 혈장 내에 녹아 있다.

(표)
조직으로 전달되는 적혈구의 수는 적혈구 농도에 따라 크게 달라지기 때문이다.

적혈구 수치는 그럼 높을수록 좋은가?

일정 농도에서 최대치를 찍었다가, 이후로는 감소함.
혈액이 끈적끈적해져서(점도가 증가해서) 조직으로 산소가 잘 전달되지 않기 때문.
너무 많으면 수액을 주거나 사혈? 을 해야 하고, 너무 적으면 수혈을 해야 한다.

#### TP (Total Protein)

또 혈장내 단백질의 농도를 측정해야 한다.
- 알부민 : 혈장내 삼투를 유지하는 데 중요한 역할을 한다.
	- 알부민이 낮다 = 삼투압이 낮다 = 혈관내 수분이 조직으로 빠져나간다 = 조직 관류량이 떨어짐, 혈압 유지 안 됨
	- 무작정 혈액을 넣어준다고 개선되지 않음. 삼투압을 높여줘야 하기 때문에 고분자물질이 있는 수액을 넣어줘야 함.
	- 혈장 단백질을 통해서 약물이 이동. 조직으로 빠져나가는 일부 약물이 마취 효과를 냄. 약물 농도 조절을 위해서도 혈장 단백질 농도가 필요.

#### Glucose

#### 신장 (BUN, Crea)

통증 → 카테콜아민 증가 → 신장 관류량 감소

복강에서 조작하다가 복강내 혈관 누르면 → 신장 관류량 감소
⇒ 마취를 깼을 때 급성 신부전이 발생할 위험이 있음.
따라서 신장수치 평가가 중요.

## 마취 위험도 평가 (ASA grade)

| Category | Physical status       |     |
| -------- | --------------------- | --- |
| 1        | 아무 이상 없이 건강한 환자       |     |
| 2        | 미약한 전신적 내과 질환         |     |
| 3        | 심한 전신 질환이 있지만 약물로 조절됨 |     |
| 4        | 심한 전신 질환, 잘 조절 안 됨    |     |
| 5        | 당장 죽어도 이상하지 않을 정도의 상태 |     |

1~2단계에서는 사망률이 1/2000 수준,
3~5단계에서는 1/250 수준
- 보호자에게 사전 고지하기에도 유용하고
- 마취 전 처치를 통해 grade를 낮춰볼 수 있다

딜레마
- 마취의 입장에서는 제일 안정된 상태에서 수술하는 게 좋지만,
- 마취 위험 때문에 수술을 지연하는 것이 환자에게 더 위험할 수 있다
- Anesthetic Risk & Treatment Benefit 양쪽을 비교하면서 결정해야 한다(정해진 답이 없다).

### 부작용

#### Vomiting & Regurgitation

가장 흔한 부작용 중 하나가 오연성 폐렴. 위내 내용물이 식도로 올라와 호흡기로 넘어갈 수 있다.
마취 전에는 조임근(Lower esophageal sphincter)이 위를 막고 있지만, 마취 후 근육 이완 + 자세를 잡기 위해 돌리다 보면 위내 내용물이 오연되기 쉬움.

어떤 경우에 위험한가?
- 호흡기로 넘어간 물질의 산도가 셀수록
- 더 많이 넘어갈수록

그래서 수술전 금식을 한다.
- 4~6시간 음식 금식 / 0~1시간 금수
- 너무 오래 금식을 하면, 위산이 계속 분비돼서 pH가 낮아진다..
- 혹은 저혈당이 발생할 수도 (→ 신경손상도 가능)
- 이런 금식의 위험이 있는 경우 금식 시간을 한시간 정도 줄일 수도 있다.

# 3. Anesthesia Equipment

- **산소 압력 차이**로 산소가 제공된다. (고압산소탱크 → 환자)
- Medical Gas Supply : 산소 말고도 의료용 가스가 있다. (이산화탄소 회색, 질소 파란색, medical gas 하얀색, ..)
	- 1) Color coding : 한국에서는 산소는 다 녹색으로.
	- 2) Diameter index safety system : 산소가 아닌 가스는 연결 직경이 다르다
	- 3) Pin index safety system
- Pressure gauges
	- 하나는 산소가 얼마나 남았는지
	- 하나는 산소가 얼마의 압력으로 들어가고 있는지 
		- 적정 압력을 넘어가면 경보음이 발생함. 
- 산소의 흐름
	- 1) 고압산소탱크에서 초록 라인을 따라 이동
	- 2) 유량계 : 마취 회로 내에서 산소가 들어가는 속도 조절
	- 3) Vaporizer : 흡입마취제를 산소에 공급하는 부품
		- 온도 보정 장치 (기압이 높으면 기화가 많이 되고, 온도가 낮으면 기화가 덜 되고.. 보정 필요
		- 온도 보정 장치 : 직경을 조절하거나, 내부 온도를 계속 같게 맞춰주거나
		- Flow rate 속도 조절 : 공기가 슉 빠르게 지나가면 기화된 흡입마취제가 얼마 못 붙으므로, 미로처럼 만들어놓거나, 표면적을 넓히거나, .. → 마취제 쪽으로 내려간 산소는 충분히 포화되어 나올 수 있도록 보정되어 있음.
- Oxygen flush valve : 회로 내 마취가스를 제거하기 위한 버튼
	- 마취 깰 때 환자에서 분리하고 마취제를 제거할 때 쓰는 버튼
	- 연결된 채로 쓰면! 환자에게 엄청 강한 압력이 가해진다
- Common gas outlet : 이 구멍이 밖으로 나와있을 수 있는데, 구멍이 막혀버리면 환자에게 산소 공급 안 됨

#### Breathing System

- Re-breathing system : 환자가 내뿜은 산소에서 이산화탄소 제거하고 다시 넣어주는 방식,
	- 산소 소모량이 적고
	- 체온 유지에 조~금 더 도움 될 수 있다
	- 회로가 길어질 수밖에 없다
	- 사강(가스 교환이 안 되는 상황)이 크다: 짧고 얕게 숨을 쉬는 소형견의 경우에는 이산화탄소를 계속 들이마시게 됨
- Non-rebreathing system : 
	- 산소 소모량이 큼
- 스위치를 누르면 rebreathing / non-rebreathing 회로가 바뀌는 기계도 있다
- 작고 숨이 얕은 소형견, 야생동물 등 → non-rebreathing이 유리 / 대형견 → rebreathing이 유리

[ Rebreathing (circle system) ]
- 일방향으로 산소가 움직여야 한다 → one-way valve 존재
- 사용하다 보면 습기가 맺힌다 → 방치하면 점점 끈적해져서 붙어버리고, 환자가 숨 쉬어도 안 열릴 수 있따
- 사용 후 건조와 소독 필요
- Breathing tube는 엄청 꾸불꾸불 → 빳빳한 표면으로 만들어두면 튜브가 접히면서 kinking되고 길이 막혀버릴 수 있다
- 경우에 따라 two  breathing limbs (두 줄), Coaxial system (통로가 좀 겹쳐있음; 호기 가스가 흡기 가스를 데우도록)

- Reservoir bag : 적절한 크기의 bag 필요 (normal tidal volume의 5-10배)
-  APL(Adjustable pressure-limiting) valve, pop-off valve : 얼마나 많은 가스가 폐기될 것인지 결정하는 밸브
