# 1. Anesthetic Depth (마취 심도 모니터링)

- 마취 모니터링의 기본은 **적절한 마취 심도**.
-  <u>환자가 외부 자극에 깨지 않는 것</u>이 마취의 기본 목표!
- 동시에 바이탈이 너무 억압되지 않아야 한다.

용어를 짚고 가자.

- 의식(Consciousness) : 뇌가 활성화 되어 있으며, 경험하는 것을 인식할 수 있는 상태.
- 마취(Anesthesia) : 약물로 의식을 가역적으로 억압한 상태.
- 마취 심도(Anesthetic depth) : 외부 자극에 의해 반응하지 않을 가능성의 정도.



>[!warning] 마취 심도 모니터링!
>![[Pasted image 20261017023854.png|800]]
>✔️ Minimum recommendations (최소한으로 모든 동물에서 확인) : 신체 징후 - 근육 긴장도, 동공 위치, 반사 반응
>➕ Advanced recommendations (필요에 따라 보다 면밀한 검사) : 흡입마취제(inhalant) 농도, EEG



### ✔️ Minimum - Physical signs

![[Pasted image 20261017030059.png|1000]]
<br><sup><b>마취 심도에 따른 신체적 변화를 정리한 표.</b> 에테르(diethyl ether) 기준이지만 대체로 비슷하다.</sup>

- 일반적인 변화일 뿐, 투여한 약물에 따라 반응이 달라질 수 있다.
	- Anticholinergics(항콜린제) : 심박수를 증가시킨다.
	- Dissociative agent(해리성 마취제) : 교감신경 자극 → 심박·호흡수가 증가하거나, 근육 강직이 나타날 수 있고, 반사 반응이 오래 유지될 수 있다.
- 따라서 하나로만 평가할 수 없고, 바이탈 수치, 생리학적 변화, 환자 상태 등을 종합적으로 평가해야 한다.

| Anesthetic level                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1단계** \| 약물 투여 시작부터 의식을 잃기까지의 단계                                                                                                                                                  |
| 자발 움직임(저항) 남아있음 / 빠르고 불규칙한 호흡 / 심박수와 혈압 증가 / 근육 톤 유지 / 반사 반응이 남아 있음 (눈꺼풀과 각막 건드려보고, 발가락 당겨보고) / 수술적 자극에 강한 반응 / 보행 비틀거림                                                             |
| **2단계** \| 의식을 잃은 뒤부터 호흡이 규칙적으로 변하기까지의 단계                                                                                                                                           |
| 의식은 없지만 자발적 움직임 있음 / 호흡이 아직 빠르고, 심박수·혈압 더 높아짐 / 반사 반응 남아 있음  / 전반적으로 <u>흥분한 듯한 모습</u><br>\*고양이에서 후두경련 위험 (후두 자극 → 근육이 강하게 수축하여 기도 직경이 좁아질 수 있음)                                     |
| **3단계** \| 의식을 완전히 잃고 반사 반응이 점차 소실되는 단계                                                                                                                                             |
| 호흡이 느리고 규칙적 / 근육이 점차 이완됨 / 심박수·혈압 감소 / 반사 반응 점차 소실 / 수술 자극에 대한 반응 점차 소실 (적절한 마취 심도에서는 아예 없음) / 동공의 위치가 ventromedial 방향으로 내려감 (그러다 다시 중앙으로)<br>\*가장 이상적인 심도는 <u>stage Ⅲ - medium</u> |
| **4단계** \| 마취 심도가 지나치게 깊어져 CNS가 심하게 억압되는 단계                                                                                                                                         |
| 심혈관계 억압 / 호흡 정지 / 신경계 반응 소실 / 사망에 이를 수 있음                                                                                                                                           |

전체적으로는 
- 기억 관련 부위 억압 → 환자는 기억 못함
- 억제신경계가 먼저 차단 → 처음에는 흥분하는 듯 보임
- 의식 관련 부위 억압 → 의식을 잃고
- 척수 억압  → 근육이 이완되고 반사 반응이 차단됨
- 더 깊어지면 호흡기·심혈관계 억압

⇒ 임상에서 가장 많이 체크하는 것은 동공의 위치, jaw tone(턱 벌려보기), 반사 반응!

### ➕ Advanced: Inspired/expired inhalant concentrations (흡입마취제 농도 평가)

![[Pasted image 20261017033926.png|1000]]

- 산소내 흡입마취제 농도와 혈액내 흡입마취제 농도가 평형을 이루면 마취가 유지된다.
- 단, 어떤 상태로 평형을 이루는지는 가스 종류에 따라 다르다.
	- 기화된 양이 많은 채로 평형을 이루는 가스도 있고(sevoflurane) <font color="#7f7f7f">→ 빨리 마취되고 빨리 깬다</font>
	- 액체에 녹은 양이 많은 채로 평형을 이루는 가스도 있다(isoflurane) <font color="#7f7f7f">→ 마취되기까지 오래 걸린다</font>
- 특정 농도에서의 마취 효과도 마취제의 종류에 따라 다르다.
	- isoflurane 2%와 sevoflurane 2%는 마취 효과가 다르고,
	- 같은 약제라도 종에 따라 마취 효과가 다르다 (사람? 개? 고양이?)
- 그래서 같은 기준으로 평가하기 위해 사용하는 것이 MAC!


>[!check] MAC (Minimum alveolar concentration) - 최소폐포농도
>건강한 개체의 50%가 통증 자극에 반응하지 않을 폐포내 마취제 최소 농도
>
>![[Pasted image 20261017034605.png|350]]

- 고양이에서 isoflurane 1.7 = 개에서 1.3
- 고양이에서 sevoflurane 3.0 = 개에서 2.3
- 이런 식으로 종마다 다르다!
- 0.8MAC 이라고 하면 = 1MAC 농도의 0.8배 수준으로 투여한다는 뜻.

### ➕ Advanced: EEG-based monitoring

보다 정확한 평가를 위해서 뇌파를 평가할 수 있다. 
(아직 수의학에서 일반적으로 사용되지는 않지만, 사람 의학에서는 기본적으로 다 본다~)

![[Pasted image 20261017032816.png|250]]

- 정상 뇌파 : 여러 부위, 여러 방향에서 다양한 자극이 오기 때문에 → 그 전기 신호들을 다 인식하면 저진폭·고진동수의 뇌파
- 마취 상태 : 외부 자극이 차단되어 전기 신호가 줄고, 동기화됨 → <u>고진폭·저진동수</u>의 뇌파가 나타남

뇌파라고 해서 마취 심도를 단독으로 평가할 수 있는 것은 아니다.
당연히 단일 지표만으로 평가할 수는 없다! 바이탈, 생리학적 변화와 함께 종합 평가 필요.

# 2. Circulation (순환기 모니터링)

- 적절한 조직 관류가 이루어지는지 평가한다.
- 심혈관계의 기능이 잘 수행되고 있는지 모니터링하는 것!
	- 산소와 영양소를 가진 혈액을 조직으로 전달하고,
	- 조직에서 나온 대사산물을 외부로 운반·제거~

Cardiac Output (CO, 심박출량) - 즉, 혈액이 얼마나 뿜어져 나오는지 파악해야 한다.

- 심장이 빨리 뛰면, 한 번에 더 많은 혈액이 조직으로 뿜어져 나가면 늘어나겠지? ⇒ **CO = HR X SV** 
- SV(stroke volume, 1회 박출량)는 아래 요인이 결정한다.
	- 혈액이 얼마나 차 있는지 (preload, 전부하)
	- 얼마나 세게 수축하는지 (contractilitiy, 수축력)
	- 저항이 얼마나 있는지 (afterload, 후부하) → SV에 영향을 준다.

![[Pasted image 20261017035834.png|300]]<br><sup><b>Preload가 많으면 CO는 증가한다. / 수축력이 높고, 저항이 낮으면 더 많이 증가한다.</b></sup>


>[!warning] 순환기 모니터링!
>![[Pasted image 20261017035036.png|800]]
>✔️ Minimum recommendations : continuous ECG (심박수 확인), Oscillometry (혈압 확인)
>➕ Advanced recommendations (필요에 따라 보다 면밀한 검사) : IBP, 동적 혈역학 수치

###  ✔️Minimum: Electrocardiography (ECG)

<font color="#7f7f7f">(이후 정리 안함)</font>

P파는 심방 수축
QRS파는 심실 수축
T파는

- 정상 심박수 : 60-160 작은 개체일수록 심박수가 빠르다.(고양이 : 작으니까 더 빠른 편. 120-240)
	- 고양이는 정상적으로도 ECG가 작게 나온다.
- 호흡성 부정맥이 도움되는 것

✔️ Electronic monitors + **intermittent subjective cllinical assessment**
- 주의! ECG는 심장이 실제로 수축하고 있는지가 아니라, 전기적 신호가 어떻게 발생하고 있는지를 보는 것.
- 따라서 실제로 심장이 수축하고 있는지 체크해주면 좋음.
	- 대퇴동맥, 발등동맥을 만져보거나, 
	- CRT 확인
	- 식도청진기 등으로 청진

AV block, PVC 등
SA node → AV block이 차단, P-QRS 사이가 차단된다.
1도 block ; 점점 간격이 늘어남.
2도 block : QRS 파가 점점 사라짐. (멀어지다가 사라지면 mobitz type 1, 동일하다가 사라지면 mobitz Ⅱ), 마취중에는 2도 제일 잘 보임

#### Heart rate

- 마취 중 서맥 발생 하면?
- 정상 심박수의 30% 이상이 감소하면 보이기 시작한다.
- 심박수의 변화가 CO에 영향을 줄 때 처치 필요

서맥 시 처치 → 항콜린제(atropin, glycopyrrolate)
- vagus nerve의 muscarinic receptor 차단 → 상대적으로 교감신경 활성화 → 심박수 증가
- Atropine : 0.02-0.04mg/kg IV or IM
- Glycopyrrolate : 0.005-0.01mg/kg IV or IM
- Atropine이 onset 시간이 짧은 편. 작동 시간도 짧은 편.

부작용?  Paradoxical effect (오히려 심박수 떨어짐)
- Block of presynaptic M1 receptor (용량이 낮으면 간혹 presynaptic M1 receptor를 먼저 차단 → 부교감신경 항진 → 심박수가 오히려 떨어지는 경우가 가끔 있음.
시간이 지나면서 심박수가 올라가는 경우도 있고,
용량을 좀더 추가해야 M2 muscarinic receptor를 block할 수도.
- Tachycardia (심박수 너무 증가)
교감, 부교감 둘 다 항진되어 있었는데, 부교감신경이 갑자기 차단되니 심박수가 미친듯이 오름.
길항할 수 있는 약물이 없음. 떨어질 때까지 기다릴 숩까에 없음.

#### Tachycardia

- 질환 때문에 발생하는 빈맥 : 심박수 조절이 필요함. β-blocker(에스몰롤) 대표적으로 사용함.

>[!note] α receptor와 β receptor
>- α-receptor 1 : 혈관 수축
>- α-receptor 2 : norepinephrine 신경 전달
>- β-1 : 심장이 더 세게 뛰게
>- β-2 : 이완. 
>- β-blocker는 β1 receptor를 차단해서 심장이 더 약하게 뛰게 한다.

###  ✔️ Minimum: Oscillometric blood pressure monitoring
#### Blood pressure

- Systolic, mean, diastolic으로 구분.
- Pulse pressure (SAP-DAP)
	- pulse는 수축-이완 차이가 크면 잘 느껴진다. 그래서 pulse만으로는 조직 관류량을 결정할 수 없다.

[측정 방법]
- Oscillometric BP monitoring
	- SAP에 오르고, MAP에 최고치, DAP에 감소한다.
	- 최소 5분 이상 측정해야 한다.
	- 60-65mmHg 이하면
		- 마취제가 부족한가? 추가 투여 필요할 수도.
		- 심박수가 느려? 혈관 안에 혈액량(preload)가 부족한가?
		-  → 수축제를 넣거나
		- CO X SVR 계산 ..을 고려
- Capnography : 환자 호흡에서 이산화탄소 분압을 보는 것.
	- 환자가 충분한 output을 만들고 있으면, 폐에도 정상적인 순환이 형성된다. → 몸의 이산화탄소가 호흡으로 빠져나온다. 
	- 이산화탄소 분압이 너무 낮다? 과환기 문제일 수도 있지만, 수축력 자체가 약해진 것일 수도 있다.
	- CO2 수치가 괜찮으면 폐순환이 잘 일어나고 있는 것.
- Oscillometric : 혈관의 진동을 측정
	- 커프를 보면 동맥이라 표시되는 화살표가 있다. 혈관 진동이 느껴지는 부위를 그 위치에 맞추면 더 측정이 잘 된다.
	- 다리 직경의 40%를 둘러쌀 수 있는 커프 사이즈를 선택.
	- 사이즈가 너무 작으면 높게 측정될 수 있고, 너무 크면 낮게 측정될 수 있다.
- Alternative
	- IBP, 등에서도 파형 개수를 카운트해서 심박수를 띄워준다. 이걸로 같이 보완적으로 참고할 수 있다.
	- 가끔 double counting, triple counting 될 수 있는데, 그럴 때 실제 심박수가 맞게 측정되고 있는지 참고해서 보완.
	- Doppler

### ➕ Advanced: IBP (침습적 혈압 측정)

- 혈관 내에 직접 삽입해서 측정하는 것으로, 준비물이 많다.
	- High-pressure tubing (동맥이 뿜어져나오지 않도록 아볅을 주는 역할)
	- Pressure transducer 
	- 희석용 heparin
- 압력은 300mmHg 정도로 준다
- Heparin 1-2 IU/mL 희석
- 잡을 수 있는 위치
	- Dorsal pedal artery
	- Coccygeal artery (고양이나 소형견에서는 더 쉬울 수도)
- 심장높ㅇ

# 3. Respiration (호흡기 모니터링)

- 혈액 내 산소가 얼마나 있는지 모니터링.

- SO2
	- 98-99%가 정상
	- <95% 면 hypoxemia
	- <90% 면 serious hypoxemia, 이대로 유지되면 위험




---

1.  폐포내 산소 분압(PAO2)과 동맥내 산소 분압(PaO2) 차이 (정상적인 차이는 < 150mmHg)
2. 동맥내 산소분압
	- 200-300이면 중등도의
