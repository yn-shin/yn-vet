#### 1) 내재적 요소

| 내재적 요소     |                                                                                          |
| ---------- | ---------------------------------------------------------------------------------------- |

###### Water Activity (Aw)

- 미생물이 이용할 수 있는 물의 양을 나타내는 지표
- 특정 수용액의 수증기압(P) / 순수한 물의 최대수증기(P0) 로 계산함. <br>⇒ 0~1 사이 값, 1에 가까울수록 자유수

- 물에 기름이 분산한 물속기름형(fat-in-water) : 크림, 우유, 아이스크림, 마요네즈 등
- 기름에 물이 분산한 기름속물형(water-in-fat) : 버터, 마가린 등
- 버터는 크림으로부터 만들어졌으며 일반적으로 크림이 버터보다 수분활성도가 높음.

- 수분활성도를 저하시키는 방법
	- 공기건조 (말린과일)
	- 농후화 (소금이나 설탕 같은 용액을 식품에 첨가)
	- 냉동보관 (얼음으로 결정구조 변경)
	- 미세구조변경 (크림 → 버터)
- 주요 미생물군의 최저 수분활성도
	- 대부분의 세균 : 0.97~0.90
	- 대부분의 곰팡이 : 0.80
- 식품의 Aw가 미생물의 최저 Aw보다 낮으면 미생물은 증식하지 못한다. ⇒ 0.86을 기준으로 본다. (대부분의 세균은 0.9x인데, Staphylococcus aureus는 0.86)

## 3.2 경구감염병

- 병원체가 입을 통해 몸 안으로 들어와 발생하는 질병

#### 발생요인과 예방대책

- 주요 경로 : 분변-경구 (분변 → 음식·물·손 → 입) 
- 발생 요인 : 병원소(reservoir)는 거의 환자 및 보균자의 분뇨에 기인함.
	- 거의 모든 식품이 전파체의 역할을 함.
	- 수계유행(water-borne infection) : 분뇨가 음용수를 오염시켜 발생
	- 식계유행(food-borne infection) : 분뇨가 음식물을 오염시켜 발생
- 수계 유행 시의 환자 발생 
- 식계 유행 시의 환자 발생
	- 보통 여름에 많다.

#### 주요 법정 경구감염병 (주요 법정 2급 수인성·식품매개감염병)

- 병원체 : 콜레라균(*Vibrio cholerae*) - 주요 콜레라균 O1형과 O139형
- 인도의 갠지스강의 삼각주에 상재 (우리나라에 상재 X)

>균종 : *Vibrio cholerae*
>혈청군 : O1·O139

> 	- Inaba : A, B
> 	- Ogawa : A, C

- 사망률은 과거에는 50% 이상이었으나 근래에는 1% 미만

2) 장티푸스 (Typhoid fever)
- 환자와 보균자의 분변에 병원소 존재
- 전파 양식 : 직접적(분변-경구), 간접적(분변에 오염된 물과 음식)
- 병원체 : 장티푸스균(*Salmonella* Typhi) Typhi는 정자
- 영구보균자의 경우 티푸스성 <u>담낭염</u> 
- 국내 발생 상황 : 2024년 34명, 2025명 33명, 지속적으로 감소 추세

##### 3) 파라티푸스 (Paratyphoid fever)

- 장티푸스와 거의 유사한 급성감염병, 전반적으로 경증
- 병원체 : 파라티푸스 A균, B균, C균 (*Salmonella* Paratyphi A, B, C)

##### 4) 세균성 이질 (Bacterial dysentery)

- 병원체 : 
	- *Shigella dysenteriae* (A군) : shiga toxin, 좀더 위험함
	- *Shigella flexneri* (B군) :
	- *Shigella boydii* (C군) 
	- *Shigella sonnei* (D군)
- 국내 발생 : 00년 제주도, 01년 도시락 유행

##### 5) 장출혈성대장균증 (Enterohemorrhagic)

- 대부분의 대장균은 장에 항상 정상적으로 존재, 대부분 위해성은 없음
- 일부 병원성 대장균은 식중독 등의 병을 일으킴
	- 장병원성(enteropathogenic), 장침입성(enteroinvasive), 장독소원성(enterotoxigenic), **장출혈성**(enterohemorrhagic)
- 병원체 : STEC(Shiga toxin-producing *E. coli*) 중 intimin을 생성하는 균주
	- intimin이 미세융모에 밀착 결합하여, 흡수융모를 손상시켜 수분흡수를 막음
	- 대표적인 혈청형은 O157:H7
- 전파양식
	- 분쇄육으로 만든 육제품, 신선 야채류, 비가열 식품, 물 오염 등
- 임상 증상 : 3~9일의 잠복기, 급격한 복통, 수양성 설사, 구토 등
- 국내 발생 현황 : 2025년 531명

- 항생제를 사용하면 독소가 더 많이 분비됨, 사용하지 않음

>[!note] EHEC, STEC
>- EHEC는 stx 유전자와 eae 유전자 모두 양성
>- STEC는 stx 유전자를 가진 E. coli를 의미 (stx1 and/or stx2)
>	- O104:H4처럼 EHEC가 아닌데(eae 유전자가 없음) EHEC 증세를 일으키기도 함, 이런 걸 HUS(Hemolytic Uremic Syndrome)라고 함
>- O104:H4 = non-EHEC, STEC (eae 음성)

##### 6) 유행성 A형 간염 (Epidemic hepatitis-A type)

- 병원체 : 유행성 간염바이러스 (Hepatitis A virus)
	- family Pincornaviridae, <u>un-envelopped</u> ssRNA
	- Enveloppe이 없어서 저항성이 있고, 소화기 감염이 가능함
- 전파 경로 : 환자의 분변, 인후두 분비물 등으로 오염된 음료수나 식품 등의 섭취를 통해 경구적으로 감염
- 임상증상 : 발열, 구역질, 식욕부진, 복통, 전신권태, 두통, 간종대 등의 증상 2~3일 → 황달(약 75%)
- 위생의 역설; 성인은 선진국에서 더 많이 발생

##### 7) E형 간염

- **인수공통감염병**
- 병원체 : Hepatitis E virus (HEV)
- 물의 질병 + 돼지 유래 식품의 One Health 질병
- 국내 발생 현황 : 2025년  (해외유입보다는 산발 감염)
- 백신은 세계적으로 보편 사용되지 않는다!

| **세균성 - 감염독소형 식중독**  | ✔️ 장내에서 원인균이 증식을 멈추고 아포를 형성하는 과정 중 생산된 독소에 의해 발생<br>     : _Clostridium perfringens_, _B. cereus_<br>✔️ 장내에서 증식 또는 사멸하는 과정 중 생산된 균체내외독에 의해 발생<br>     : _Vibrio cholerae_, EPEC, ETEC                                                                                                                        |
| (1) 클로스트리움 퍼프린젠스 식중독 | _Clostridium perfringens_<br>- 대부분 A형이 문제, A형과 F형은 100℃에서 1\~4시간 가열해도 견딜 수 있을 정도로<font color="#c00000"> 내열성이 강함</font>.<br>- 가열조리식품이 원인식품 (가열조리 → 혐기성 환경 → 근데 살아남음 , 다른 애들은 죽음 → 급속히 증식)<br>- A형 : 설사와 복통, 구토와 발열은 없음, 1\~2일 이내 회복<br>- F형 : 구역질과 구토 → 설사와 복통 → 탈수<br>- 가열 후 냉각하지 말고 즉시 섭취할 것, 섭취 직전에 재가열할 것 |
| (2) 바실러스 세레우스 식중독    | - _Bacillus cereus_, G+ 간균, 호기성, 아포형성균<br>- 설사형 : 감염독소형 (C. perfringens와 유사) / 육류, 소스 / 열에 약함<br>- <font color="#c00000">구토형</font> : 독소형 (포도상구균과 유사) /<font color="#c00000"> 밥류</font><br>- 우리나라, 일본은 대부분 구토형 식중독                                                                                           |

| **바이러스형 식중독**        | ✔️소형구형 바이러스<br>      : 노로바이러스 (Norovirus) / 로타바이러스 (Rotavirus) / 사포바이러스 (Sapovirus) / 엔테로바이러스 (Enterovirus) -소아마비바이러스(Poliovirus)도 여기 속함 / 아스트로바이러스 (Astrovirus)                                                                                                                                             |
| (1) Norovirus        | - 극심한 구토와 설사가 1\~2일간 지속<br>- Genetic cluster GⅡ.4가 가장 많은 식중독<br>    - Ⅰ, Ⅱ, Ⅳ는 사람, Ⅲ는 소 등의 가축, Ⅴ는 쥐에서 발견<br>- 다른 바이러스보다 chlorine에 저항성이 강함<br>- 지하수, 굴                                                                                                                                                        |
