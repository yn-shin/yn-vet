- **균형마취** : 전신마취의 3요소(무의식, 진통, 근이완)를 충족시킬 전신마취제 요구량을 줄이기 위해 전마취제를 투여하여 기능의 일부를 먼저 담당시키는 것.

# 1. 전마취제

- 무의식 유도를 위한 중추신경계 억제 단계
    - ① **Tranquilizer** (안정): 환자가 불안해하지 않게 할 정도의 아주 작은 용량.
    - ② **Sedative** (진정): 불안을 진정시키고 가만히 있게 함.
    - ③ **Hypnotic** (최면): 잠들 듯 말듯한 상태.

## 1.1 Tranquilizers (안정제)

#### 🔹Phenothiazines (진통X, 강한 진정) : 💊 Acepromazine

졸림 부작용이 너무 심해서 사람에서는 쓰지 않는 약물(antipsychotic).  
수의에서는 진정제로 사용한다.

|구분|내용|
|---|---|
|**작용기전**|도파민 수용체(D1, D2)를 차단 → 신경전달 방해|
|**용량**|- 0.01–0.03 mg/kg (IV, IM, SC)  <br>- 0.55–2.2 mg/kg (PO) ; PO 요구량 ↑|
|**작용시간**|- Onset: 5분  <br>- Full effect: IV 투여 후 10–15분 (대략 얼마나 지나면 효과 나타나는지 알고 있어야)  <br>- Duration: 4-6시간으로 긴 편|
|**기타 효과**|- 혈관의 α1 수용체 차단 → 혈관 이완, 저혈압 가능성 ↑  <br>- Hematocrit 감소: 비장 주변의 인대, 근육 이완 → 혈액이 비정상적으로 비장에 몰리면서 순환 혈액 속 적혈구 감소.  <br>- 체온 감소: 혈관 이완 → 열 배출 증가 → 저체온증 위험.  <br>- 항구토 효과: 구토중추에 작용 (CRTZ and vomiting center)|
|**주의사항**|- 대형견에 똑같이 '체중당 용량'을 적용하면 진정 효과가 너무 강할 수 있다. (전체 체중에서 지방이 차지하는 비율이 높기 때문) → 0.005–0.01 mg/kg 정도의 낮은 용량이 권장된다.  <br>- Boxer가 이 약물에 민감한 편 → 0.005 mg/kg 정도의 낮은 용량과 모니터링.  <br>- 약한 항히스타민 효과가 있다: 피부 알레르기 검사 전에는 권장 X.  <br>- 약물 자체가 호흡을 크게 억제하지는 않는다. 하지만 고개를 늘어뜨려서 기도 저항이 커질 수 있다. 자세로 인한 영향과 약물 효과를 구분한다.|

>[!quote] 아드레날린성 수용체 (Epi, NE에 작용)
> - α1 - 혈관 수축 , α2 - 노르에피네프린 분비 조절
> - β1 - 심근 수축력, β2 - 평활근 이완

#### 🔹Benzodiazepines (진통X, 약한 진정) : 💊 Diazepam & Midazolam

약한 진정 효과가 있어 병원에 오는 환자의 진정 목적으로 흔하게 사용된다.
![[Pasted image 20261125185715.png|200]]
**제품명은 도미토(Domitor).**

| 구분        | 내용                                                                                                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **작용기전**  | - 변연계(Limbic system)의 GABA(Gamma-aminobutyric acid) receptor는 억제성 신호 전달에 관여.  <br>- Benzodiazepines는 GABA의 억제작용을 강화 → 진정효과                                              |
| **용량**    | - 0.1–-0.3 mg/kg → 전마취제                                                                                                                                                 |
| **작용시간**  | - Onset: 5분.  <br>- Duration: 미다졸람 1h, 디아제팜 3h → but 환자마다 편차가 크다.  <br>(미다졸람은 간에서 대사되기 전에 작용, 디아제팜은 대사 후에도 활성 대사산물이 작용 → 디아제팜의 작용시간이 더 길다는 걸 기억하자.)                     |
| **기타 효과** | - 항경련 효과(Anticonvulsant effects) : 경련 잡을 때 first line.  <br>- 항불안 효과(Antianxiety), 진정과 최면.  <br>- 근육이완: 척수 수준에서 작용 (신경근접합부 X).  <br>- 기억 못하게 하는 효과 (사람에서도 내시경에 미다졸람 선호) |
| **주의사항**  | - 건강한 환자에게는 거의 효과가 없거나, 억제 행동을 잃고 흥분할 수도 있다.  <br>- 기저질환이 심하고, 나이가 많아 마취 위험도가 높은 환자에서 흔히 선택된다.  <br>(심혈관계에 미치는 영향이 비교적 작고 안정적)                                          |
| **길항제**   | - **Flumazenil** (Acepromazine은 길항제가 없지만, Benzodiazepines는 있음!)  → 0.01-0.03 mg/kg (IV, IM)<br>- Onset 1-2분. (발현이 빨라 거의 들어가자마자 깬다.)                                     |

#### 🔹α2 작용제 (α-2 adrenoceptor agonists / 진통O, 강한 진정) : 💊 Medetomidine

| 구분             | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **작용기전**       | - 노르에피네프린이 분비되는 α2 receptor에 작용제가 결합하면 NE의 추가 분비가 억제된다.<br>  : 소량만 들어가도 진정 효과가 강한 약물.                                                                                                                                                                                                                                                                                                                                                                                                |
| **용량**         | - 5–-20 mcg/kg (IV, IM) : 정맥주사는 낮은 용량, 근육주사는 높은 용량.<br>- 이미 전신마취가 되었거나, 심혈관계 영향을 줄이고 싶을 때는 저용량 (1–3 mcg/kg, IV)                                                                                                                                                                                                                                                                                                                                                                      |
| **작용시간**       | - Onset: IV 3-–4분, IM 10-–15분. (근육흡수까지 시간이 소요됨)<br>- Duration: 30분-–1.5시간.                                                                                                                                                                                                                                                                                                                                                                                                           |
| **길항제**        | **Atipamezole** [안티세단]<br>  - Medetomidine은 진통&진정 → 길항하면 진통 효과도 사라진다.<br>   (Atipamezole이 아프게 하는 게 아니라, Medetomidine의 진통 효과가 사라진 것.)<br>   - 보통 메데토미딘 + 케타민 조합해서 쓰는데 (고용량 케타민에 따른 경련 예방),<br>    이 상태에서 메데토미딘을 길항 → 경련을 보일 수 있다(ketamine convulsive action may be revealed).                                                                                                                                                                                                         |
| **특징적 반응**     | ![[Pasted image 20261125231743.png\|250]]<br>**Phase 1** \| <u>immediate response → increase BP → decrease HR</u><br>- 초기: 말초혈관이 수축하면서 혈압이 갑자기 오른다. (α1에 작용)<br>- Baroreceptor에 감지되면 보상성으로 심박이 떨어진다.<br>⇒ 고혈압 & 반사성 서맥 (reflex bradycardia).<br>**Phase 2** \| <u>return of BP normal values → but, HR remains low</u><br>- 시간이 지나면서 혈압이 정상화되거나 약간 저혈압 → 부교감신경 영향으로 서맥은 남아있을 수 있다.<br>\* 투여 초기 혈관수축에 따라 점막창백이 나타날 수 있다. (당황하지 말기)<br>\* 맥박 신호가 약해져 pulse oximetry도 측정이 잘 안될 수 있다.    |
| **권장되지 않는 상황** | - <u>심혈관 질환이 있는 환자</u>에서는 부담이 크다.<br>- 진정 효과가 강해 <u>정신 질환이 심한 환자, 나이가 많은 환자, 너무 어린 환자</u>에서도 권장하지 않는다.<br>- 췌장에 작용해 혈당이 확 올랐다가 떨어진다 → <u>당뇨병 환자</u>에게도 권장되지 않는다.                                                                                                                                                                                                                                                                                                                     |
| **주의사항**       | - 대뇌 기능의 완전한 억제가 아니라 신경전달을 억제하는 것<br>   → 겉보기에는 깊이 진정된 것 같았는데 만지면 갑자기 일어나 물 수도 있다.<br>   → 다른 약물을 함께 쓰면 이런 반응이 덜하다.<br>- **항콜린제 병용 주의** : 서맥 작용 때문에 예전에는 항콜린제<sub>(무스카린 수용체 차단해서 심박수 높임; 글리코피롤레이트, 아트로핀)</sub> 병용.<br>   → 혈관 수축 상태에서 보상적으로 심박수가 낮아진 건데, 항콜린제로 혈압 더 높였다가 폐혈관, 뇌혈관 손상되기도.<br>   → 초기에는 주의, 말초혈관 수축 시기가 지나고 혈압이 내려왔는데도 서맥이면 그때 추가 처치를 고려한다.<br>- 요즘은 체내에서 주로 작용하는 활성 이성질체만 뽑아 dexmedetomidine을 많이 쓴다.<br>   (용량 대비 효과 2배, medetomidine 0.1mL = dexmedetomidine 0.05mL) |
